# Epistemic Stance of the Project

The project separates three kinds of knowledge:

1. **Observed (measurement).** Fixed cameras, ACS demographics, LODES commute
   flows. A disparity found here is a finding. See [[camera-layers]].
2. **Modeled (routing/choice).** How people traverse activity space. Standard
   calibrated models with sensitivity analysis. These change the fidelity of
   exposure along observed flows, not the flows themselves. See [[mode-choice-mnl]].
3. **Speculative (assumption-driven).** Tesla / robot / glasses layers. Excluded
   from empirical claims; kept for a separate prospective paper. See
   [[foresight-scenario-layers]].

The tool side carries the same honesty: every number is a model estimate with
stated provenance; the app is an estimate tool, never a surveillance map or an
evasion guide; the route never leaves the browser. See [[civic-tool-ethics]].

Causal stance: observational with confounding control, never causal-from-
randomization. The disparity is the demographics→exposure path net of legitimate
placement channels — and the analysis turns on which channels count as legitimate
([[results-laundering-ladder]]).
